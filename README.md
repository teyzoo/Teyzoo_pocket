# Pocket Signal Bot

Telegram-бот для анализа валютного рынка и генерации торговых сигналов.

## Возможности

- Закрытый доступ через заявки.
- Одобрение пользователей администратором.
- Автоматические сигналы.
- Ручной запрос сигнала.
- CALL / PUT.
- Конкретное время входа.
- Время МСК / UTC+3.
- EMA.
- RSI.
- MACD.
- Bollinger Bands.
- Stochastic.
- ATR.
- Support / Resistance.
- Quality Score.
- История сигналов.
- Статистика.

## Переменные Render

BOT_TOKEN
ADMIN_ID
TWELVE_DATA_API_KEY

## Запуск

```bash
pip install -r requirements.txt
python main.py
